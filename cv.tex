\section{Projects}

\project{Skillify AI}{-- AI learning platform}{\href{https://github.com/Tudor810/Skillify}{GitHub}}
\begin{bullets}
\item Built and deployed a full-stack learning platform (React, Node.js/Express, MongoDB) with an AI tutor on the OpenAI API that explains topics, quizzes users and adapts to their progress; reached 24k sign-ups.
\item Implemented a freemium model with Stripe Checkout subscriptions, Google sign-in, RS256-signed JWT authentication and transactional email (Nodemailer).
\item Added document, image (OCR with Tesseract.js) and YouTube summarizers that extract the text and pass it to the LLM.
\end{bullets}

\project{CORE-Speech}{-- \textbf{2nd place, PoliHack 2026}}{\href{https://github.com/Tudor810/CORE-Speech}{GitHub}}
\begin{bullets}
\item AR-glasses system that lets Deaf and hearing people talk in real time: sign language to speech, and speech to captions on the glasses.
\item Handled system integration: connected sign recognition (MediaPipe, PyTorch LSTM), a local LLM (Ollama), voice cloning (OpenVoice, MeloTTS) and speech-to-text (Vosk) into one real-time pipeline.
\item FastAPI edge server streaming audio over WebSockets to the ESP32-S2 firmware on the glasses (I2S microphone, display).
\end{bullets}

\project{Chess Engine}{-- C++, UCI protocol}{\href{https://github.com/Tudor810/ChessEngine}{GitHub}}
\begin{bullets}
\item Bitboard move generation (magic bitboards, Zobrist hashing), verified with the standard perft tests.
\item Negamax alpha-beta search with iterative deepening, quiescence search, null-move pruning, MVV-LVA move ordering and a transposition table.
\item Tapered PeSTO evaluation and time management; scores around 2000 Elo CCRL.
\end{bullets}
